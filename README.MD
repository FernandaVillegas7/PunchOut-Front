# Tienda en Línea

Este proyecto es una tienda en línea básica creada utilizando PHP y Twig como motor de plantillas. Es un ejemplo de cómo se puede estructurar una aplicación sencilla para manejar productos, carritos de compras y procesos de pago de manera modular.

## Requisitos

Para ejecutar este proyecto de forma local necesitarás:

- PHP 8.2 o superior.
- Composer (para la gestión de dependencias).
- Servidor web local como Apache o Nginx (puedes usar XAMPP, WAMP, o cualquier otro).

## Instalación

Sigue estos pasos para instalar y ejecutar el proyecto en tu máquina local:

1. Clona este repositorio o descarga los archivos.

   ```bash
   git clone https://github.com/mersolDevOps/b2c.git

2. Instala las despendencias del proyecto con composer
    ```bash
    composer install

3. Abre el navegador y accede al sitio en base a tu servidor local

## Estructura del Proyecto
- /public: Carpeta que contiene los archivos accesibles públicamente, como el punto de entrada index.php.
- /app: Carpeta con la lógica del proyecto, incluyendo controladores y modelos.
- /templates: Carpeta donde se encuentran las plantillas Twig para las vistas.
- /vendor: Carpeta generada por Composer con las dependencias.
